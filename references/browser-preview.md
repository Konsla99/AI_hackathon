# Browser 미리보기 확인

웹 서비스를 왼쪽 **Browser** 도구에서 확인할 때만 참고합니다.

1. 프로젝트에 있는 실행 명령으로 서버를 시작합니다.
2. 터미널 출력에서 서버의 **실제 포트**를 확인합니다. `3000`은 예시일 뿐이며 과제에서 포트를 고정한 것이 아닙니다.
3. 서버를 `0.0.0.0`에 바인딩합니다. `localhost`에만 바인딩하면 미리보기 연결이 되지 않을 수 있습니다.
4. Browser 연결 화면의 **PORT**에 실제 포트를, **URL**에 확인할 경로를 입력합니다. 예를 들어 루트 화면은 `/`입니다.
5. 오른쪽 원형 화살표를 눌러 연결합니다. 터널을 만들거나 접속 주소를 직접 조합하지 않습니다.
6. 서비스가 표시되면 버튼·입력·이동 기능을 직접 사용해 요구사항을 확인합니다.
7. 확인을 마칠 때까지 서버를 실행한 터미널을 유지합니다. 문제가 있으면 포트, 바인딩 주소, 서버 실행 상태를 먼저 다시 확인합니다.

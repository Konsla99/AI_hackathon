# 간단 작업 계획

Codex `/plan`이나 Superpowers 계획 스킬을 이미 사용했다면 이 양식을 중복 작성하지 않습니다. 계획 파일이 필요하지만 다른 계획 기능을 쓸 수 없을 때만 사용합니다. 사용자가 준 요청 전체를 복사하지 말고 목표와 완료 기준을 간단히 적습니다.

## 목표와 완료 기준
- (입력)

## 요청 원문 위치 (필요한 경우)
- (프롬프트, README 또는 명세의 경로)

## 변경 범위
- 수정: (입력)
- 유지: (입력)

## 단계
1. 지문과 기존 프로젝트를 읽고 필수 동작을 확정한다.
2. 가장 작은 완성 흐름을 구현한다: (입력)
3. 저장소에서 확인한 방법으로 실행한다: (명령 입력)
4. 제공 Browser에서 직접 확인하고 필요한 문제를 수정한다: (흐름 입력)

## 검증
- 명령 / 실행 결과: (입력)
- Browser 수동 확인: (입력)
- 수정 후 재확인: (입력)

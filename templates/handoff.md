# 세션 인계

새 세션 사용이 허용되고, 새 메인 세션이나 다른 작업자가 같은 저장소의 변경 작업을 이어갈 때만 사용합니다. 같은 세션을 계속 쓰거나 질문만 하는 보조 대화에는 만들지 않습니다. 초기 프롬프트 전체를 복사하지 말고, 새 세션에서 필요한 진행 상태만 기록합니다. 동일 파일을 동시에 수정하지 않습니다.
